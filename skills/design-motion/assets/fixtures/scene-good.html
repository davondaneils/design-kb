How a run works

  1. Approve once

    One approval covers every payment in the run, with each amount and its arrival date shown before you confirm.

  2. Watch it send

    Each payment moves from queued to sending on its own line, so you can see which bank is still working on it.

  3. See it land

    A payment turns to paid when the receiving bank confirms it, and the paid total adds it in the same moment.

Questions

When does a payment show as paid?

When the receiving bank confirms the credit. Until then the line says sending, with the bank that is holding it.

Can I stop a run after approving it?

Yes, any line that is still queued can be stopped. Lines that are already sending finish, and the run shows which ones.
