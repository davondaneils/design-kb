# Research 06: Dashboards that answer a question

Researcher, 2026-10-09. Access method and status codes as in research 01. Dashboard grid and KPI row responsive rules are in `kb/research/layout/` (design-layout reference 05); chart rules are in the dataviz skill.

## Key findings
1. NN/g defines a dashboard as at-a-glance information people can act on quickly, in a single page; dashboards focus on one task.
2. Operational dashboards serve time-sensitive work; analytical dashboards support analysis and decisions. The split decides layout.
3. Encodings: position and length; avoid pies, donuts, area, 3D; never color for magnitude.
4. Stripe Home shows analytics plus "important notifications, like unresolved disputes" and lets people add or remove widgets.
5. Stripe Dashboard mobile app and web share metrics; Vercel overview shows all projects regardless of status.
