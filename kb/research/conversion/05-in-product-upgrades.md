# Research: 05 In-product upgrade and trial prompts

Researcher, 2026-10-10. Method as in note 01.

## Key findings
1. Interruptions unrelated to the user's goal are perceived as annoying; use nonmodal when the task is not critical; NN/g criticises a modal that "appears within the first 3 seconds" (C36).
2. Apple requires a subscription ask to describe what the user gets for the price, with concrete units ("How many issues per month? How much cloud storage?") (C37). Non-subscription trials must state duration, what stops working, and later charges (C37b).
3. Vercel's pricing shows usage-based plans as an included allowance then a rate, and says what happens at the cap on free plans: "limited to the usage caps and cannot purchase additional usage" (C46). The in-product pattern this implies (meter, allowance, overage) is opinion until a measured source exists.
4. No tier 1 to 3 study of in-app upgrade prompt timing was found in this pass. Search returned only practitioner skills and blogs (tier 5). The chapter's timing rules are opinion built on C36 and C37 and labelled so.
