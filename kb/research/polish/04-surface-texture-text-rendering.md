# Research: 04 Surface, texture, text rendering

Accessed 2026-10-09. Tiers and status as in 01.

## Key findings
1. Gradient banding: one fix is "to make the gradient noisy"; technique uses `feTurbulence` `type='fractalNoise'` as a displacement map; `baseFrequency` around .97 for fine grain; `numOctaves` rarely above 3 or 4 "because of performance cost"; `color-interpolation-filters='sRGB'` for consistent results (Ana Tudor via Frontend Masters blog, tier 4 practitioner with extensive inspectable demos).
2. `feTurbulence` "creates an image using the Perlin turbulence function" (MDN).
3. Forced colors: non-url `background-image` is forced to none, so CSS gradients vanish there (MDN forced-colors). Texture must never carry information.
4. `-webkit-font-smoothing: antialiased`: "Switching from subpixel rendering to anti-aliasing for light text on dark backgrounds makes it look lighter"; only works on macOS; `font-smooth` is non-standard (MDN). design-typography `05` already says do not set it globally by habit.
5. `font-optical-sizing: auto` is the default; "small text sizes are often rendered with thicker strokes and larger serifs, whereas larger text is often rendered more delicately" (MDN).
6. `text-rendering: optimizeLegibility` is "not recommended for typical articles due to potential performance impacts"; browsers already apply it automatically under 20px in some cases (MDN). So setting it globally is a cargo-cult move.
7. `text-wrap: balance` limited to six lines in Chromium, ten in Firefox; `pretty` "favors better layout over speed" for body (MDN).
8. `color-scheme` changes canvas, scrollbars, form controls and spellcheck underline colors to match the scheme (MDN). Without it, a dark page shows light scrollbars and white native inputs.
9. `accent-color` styles checkbox, radio, range and progress (MDN).
10. Linear uses LCH for theme generation because it is perceptually uniform (team blog); design-color already standardizes on OKLCH for ramps.
