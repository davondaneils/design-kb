# Research 04: Illustration

Status key: **C** consensus, **X** contested, **O** opinion.

## Key findings

| # | Claim | Source | Status |
|---|---|---|---|
| 1 | Atlassian defines in-product illustration types: Spot (a single concept; empty states, errors, celebrating wins; colorful for emphasis, neutral for routine), Low-fidelity UI (onboarding, feature tours; basic shapes, sharp corners, mostly gray), Ambient pattern (background texture). | Atlassian Design, Illustrations [L1] | C (design system) |
| 2 | Illustrations "should work with the message, not replace it"; decide first whether one is needed; do not overuse (cognitive load); consider icons, copy or patterns first. Collage and purely decorative styles are for marketing only. | Atlassian [L1] | C |
| 3 | Do not use real screenshots inside product illustrations (screen within screen confusion). | Atlassian [L1] | C |
| 4 | Dropbox: illustration explains abstract, complex or dry concepts with "simple, charming scenes and metaphors," and softens error messages; tiers are Hero, Spot and Mini. | Dropbox brand imagery [L2] | C |
| 5 | Dropbox's spot library was built as a growing family by one studio to hold a consistent style. | Animade case study [L3] | C (example) |
| 6 | Decorative images take alt=""; meaningful ones get a brief alt. | W3C WAI decision tree [L4] | C |
| 7 | Graphics that are required for understanding need 3:1 non-text contrast; decorative ones do not. | W3C 1.4.11 [L5] | C |

## Conflicting views
- Generic flat "corporate Memphis" people style: widely criticized since about 2020 as interchangeable across brands. (O, broad practitioner consensus)
- Illustration vs photography for trust: photography for proof, illustration for concept (Dropbox) is the mainstream rule; some brands run illustration only by design. (X)

## Practitioner tier (opinion)
- Mature systems publish a style spec: palette subset, line weight, corner treatment, light source, perspective, character proportions, texture rules, and a do/don't board. Observed across Atlassian, Dropbox, Mailchimp (Wink Creative system, described at [L6]).
