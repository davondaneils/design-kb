About

Glasgow is built from red sandstone, cut and set in courses. For one weekend in April, letter carvers, lithographers, printers and type designers show how words are drawn, cut, set and pulled, and you get to pull one yourself.

Programme

Talks in the main hall, workshops in the print studio, and the type fair on the ground floor, 10am to 6pm both days.
