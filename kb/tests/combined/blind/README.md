# Blind pairs: combined pages against the color pilot

Three pairs, A and B. One side is the color pilot's with-skill page (`kb/tests/design-color/`), the other is the combined page built through design-director with every skill (`kb/tests/combined/`). Copy differs between them, so judge the design, not the words. For each pair, pick the one you would ship and say in one line why. Then say whether either one is "special" (Jordan bar) or only better.

1. pair-1: coffee landing page, desktop, light
2. pair-2: coffee landing page, phone, dark
3. pair-3: analytics dashboard, desktop, light

A and B were assigned by a seeded coin flip. The key is not in this repository; ask Davon for it after ranking.
