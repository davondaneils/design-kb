# Domain plan: graphic design (design-graphic)

Owner hat: editor-in-chief. Skill: `design-graphic`. Slug: `graphic`.

## Scope
Logos and identity systems, icon systems, photography and image direction, illustration systems, composition for social and marketing graphics, and file formats and export.

Out of scope (owned elsewhere, link by name): palettes and contrast math (design-color), font choice and type scales (design-typography), page grids (design-layout), animating marks and icons (design-motion), headline and caption copy (design-copy, copywriting), image delivery code beyond the essentials (design-frontend), image SEO strategy (design-search), positioning and naming (website-strategy).

## Quality bar
Fundamentals gate first: legibility at the smallest real size, one-color viability, contrast where WCAG requires it, correct formats and dimensions, text alternatives, consistency across a set. Above the gate: the moves a top identity studio uses and a strong generalist misses.

## Foundation contract
All defaults align with the shared design-kb foundation contract v0.1: 4px spacing scale, 1.25 type scale (12, 14, 16, 20, 25, 31, 39, 49, 61), semantic color roles, radius 0/4/8/12/16/full, WCAG 2.2 AA floor, 24x24 CSS px minimum target and 44x44 preferred, token names `--{category}-{role}-{variant}`.
