# Brief 02: Icon systems

**Question:** How do I choose, draw or extend an icon set that is legible, consistent and accessible?

**After reading, a designer can decide:** library vs custom; grid, stroke, padding, corner and cap specs; icon sizes paired with text sizes; outline vs filled usage; when an icon needs a label; contrast and target rules; delivery (SVG, currentColor, components).

**Must cover**
- Platform specs: Material system icons and Material Symbols axes, Lucide's published guide, Apple Icon Composer app icon specs, Android adaptive icons.
- Optical size and stroke scaling.
- Recognition research (NN/g): few universal icons, visible labels, the 5 second rule.
- WCAG 1.4.11 non-text contrast and 2.5.8 target size.
- App icons and favicons as derivations of the logo, not shrunken logos.

**Test briefs it should pass**
- A custom set for a hockey pool app that sits beside 14 and 16px text.
- An app icon for iOS and Android from an existing wordmark brand.
