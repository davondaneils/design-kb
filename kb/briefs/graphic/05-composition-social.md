# Brief 05: Composition, social and marketing graphics

**Question:** How do I compose a single graphic (social post, link preview card, ad, poster) so it reads instantly at the size people actually see it?

**After reading, a designer can decide:** the focal point and hierarchy; canvas size and safe zones per placement; minimum text size on a given canvas; word budget; templates that keep a series consistent.

**Must cover**
- Composition fundamentals: one focal point, at most 3 hierarchy levels, alignment, contrast of scale, negative space, grid.
- Thumbnail math: canvas pixels to on-screen pixels.
- Official placement specs (Open Graph via Meta, X cards) and volatile ones (Instagram grid), labeled with dates.
- Template systems for a series.

**Test briefs it should pass**
- Launch set: OG image, X post, Instagram carousel for a product launch.
