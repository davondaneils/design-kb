# Brief 03: Positioning

## Question
What is this the only one of, for whom, against which named alternatives, and which one true fact proves it?

## Audience
Claude filling the positioning, one true fact and proof lines of the strategy brief.

## Decisions the reader must be able to make
- Work Dunford's components in her order: competitive alternatives (including the status quo), unique attributes, value, best-fit customers, market category.
- Choose the market category frame whose assumptions favor the brand.
- Write the onlyness statement and run the name-swap test against 3 named competitors.
- Pick the one true fact (specific, checkable, owned) and the proof that carries it to the page.
- Decide which public claim the evidence allows ("only", "first", "fastest" are objective claims).

## Fundamentals
Status quo is an alternative. Swap test passed against named competitors. Every public claim traced to evidence held before publishing (FTC, CAP 3.7).

## Expert layer
Positioning (in-market choice) versus distinctiveness (recognition); the positioning statement is an output, not a method; category frame as a design decision (the category word in the hero).

## Must cover
Dunford components and order; Neumeier onlyness; Sharp and Romaniuk on perceived differentiation; claim substantiation.

## Out of scope or reuse
Ries and Trout one word, category design, Hormozi niche test, tagline territory: website-strategy stage 4.

## Test briefs
1. Invoicing tool entering a crowded category. 2. Specialty coffee roaster.

## Rubric
Components in order; swap test result recorded; one true fact with its source; no unsupported "only".
