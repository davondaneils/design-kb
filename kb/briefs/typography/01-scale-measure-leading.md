# Brief 01: Scale, measure and leading

**Question it answers:** What sizes, line lengths and line heights should a product or site use, and how do they change across screens?

**After reading, a designer can decide:**
- The type scale (ratio, steps, tokens) and when to deviate from the shared 1.25 default.
- Body size per platform (web, iOS, Android) and the floor for small text.
- Measure for a text column and how to enforce it in CSS.
- Line height per size, and how to snap it to the 4px grid.
- Whether and how to make sizes fluid without failing WCAG 1.4.4.

**Must cover:** WCAG 1.4.4, 1.4.8, 1.4.12 numbers; Bringhurst 45 to 75 / 66; Butterick ranges; Apple HIG Dynamic Type table; Material 3 type scale tokens; the 2.5x fluid rule; tracking that varies with size; rem vs px; iOS 16px input zoom.

**Test briefs it must pass:** a stats app type system; a long-read article template; a marketing hero with fluid display type.
