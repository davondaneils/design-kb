# Brief 04: Hierarchy in UI and editorial

**Question it answers:** How do we make the reading order obvious with as few type styles as possible?

**After reading, a designer can decide:**
- How many styles a screen needs and which levers (size, weight, color, case, space) to pull, in what order.
- UI hierarchy: labels, values, headings, metadata, buttons, inputs, tables.
- Editorial hierarchy: headline, dek, byline, body, subheads, pull quotes, captions.
- Spacing rules that bind headings to the content they introduce.
- How text-wrap and text-box-trim improve headings and buttons.

**Must cover:** Material 3 roles, Apple text styles, Pimp my Type hierarchy rules, NN/g glanceable type, MDN text-wrap and text-box, WebKit pretty.

**Test briefs it must pass:** a stats dashboard; a long-read article template.
