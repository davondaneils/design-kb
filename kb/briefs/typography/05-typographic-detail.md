# Brief 05: Typographic detail

**Question it answers:** Which small details separate professional type from default type, and how to implement each on the web?

**After reading, a designer can decide:**
- Correct characters: quotes, apostrophes, primes, dashes, minus, multiply, ellipsis, nonbreaking spaces.
- Numerals: lining vs oldstyle, tabular vs proportional, slashed zero, fractions, ordinals.
- Caps and small caps: when, how much tracking, real vs fake.
- Kerning, ligatures, case-sensitive forms, stylistic sets; font-variant vs font-feature-settings.
- Alignment, hyphenation, hanging punctuation, faux styles.

**Must cover:** Butterick key rules, MDN font-variant-numeric, OpenType feature tags, WCAG 1.4.8 justification, lang attribute, practitioner posts on tabular-nums.

**Test briefs it must pass:** all three test briefs (detail must show up in each).
