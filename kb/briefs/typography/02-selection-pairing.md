# Brief 02: Font selection and pairing

**Question it answers:** Which typefaces fit this brief, and how many, in what roles?

**After reading, a designer can decide:**
- Whether one family is enough (usually yes) or a pair earns its cost.
- How to pick a face by role: display, text, functional (UI, data, code).
- How to pair: superfamily, look-alike, single-axis contrast, shared origin; and how to spot a conflict.
- What to check before committing: language coverage, styles, figures, optical sizes, confusable glyphs, rendering at 14px, license, file weight.

**Must cover:** Typekit pairing methods (Seltzer), Google Fonts Knowledge on superfamilies, Pimp my Type roles, Web Almanac popularity data (distinctiveness), NN/g glance study (condensed penalty), Apple guidance on light weights.

**Test briefs it must pass:** a hockey stats app pairing; a premium editorial brand; a fintech dashboard needing tabular figures.
