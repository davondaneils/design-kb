# Brief 03: Visual hierarchy and gestalt

## Question it answers
How do I make the most important thing get seen first, and make groups read as groups, without decoration?

## After reading, a designer must be able to decide
- The one primary element per view and how it wins (size, contrast, position, space).
- How many levels of emphasis a view can carry before it turns to noise.
- Whether to group with space, a common region (background or border), or a divider, in that order of preference.
- Where to place content given how people actually scan (layer-cake, left-leaning attention, fold).
- How to keep visual order, DOM order and focus order in agreement.

## Must cover
- NN/g scanning patterns, left-attention data, fold data.
- Gestalt proximity, similarity, common region, alignment, with UI consequences.
- Emphasis by de-emphasis (Refactoring UI).
- Squint or blur test as the acceptance check.
- WCAG 1.3.2 and focus order when CSS reorders content.

## Test briefs it must pass
- "Our dashboard header feels busy and nothing stands out."
- "Make the primary call to action on this checkout step obvious."
