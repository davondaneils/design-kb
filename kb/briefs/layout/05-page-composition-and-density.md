# Brief 05: Page composition and density

## Question it answers
What is the proven skeleton for common page types, and how dense should each be?

## After reading, a designer must be able to decide
- Section order, widths and spacing for a landing page, dashboard, article and pricing page.
- Cards vs list vs table for a collection.
- Density level (comfortable, default, compact) for a given user and task, and how to implement it without breaking targets.
- Table layout rules (alignment, figures, rules, sticky headers).
- Pricing layout: plan count, recommended plan, comparison table, mobile.

## Must cover
- Hand-offs: copy and offer to copywriting, sales-funnels and website-strategy; charts to design-data.
- NN/g cards vs lists, dashboards; Smashing pricing research; Few on dashboards.
- Practitioner tier (Linear redesign, Designjoy) labeled as opinion.

## Test briefs it must pass
- "Design the pricing page layout for a 3-tier SaaS with 30 features."
- "Lay out an ops dashboard for a support team lead."
- "Landing page for a design subscription service."
