# Brief: Navigation and information architecture

## Question it answers
How should people find their way around a site or app, at every screen size?

## After reading, a designer can decide
- Which navigation pattern to use (top bar, sidebar, tab bar, nav rail, drawer, priority+, hamburger) given item count, platform and width.
- How many top-level items to show and how to label them.
- When to use pagination, "load more" or infinite scroll.
- How to show location (titles, active states, breadcrumbs) and how Back should behave.

## Must cover
- NN/g hidden navigation study numbers (desktop and mobile).
- Apple HIG tab bar rules; Android adaptive navigation defaults and window size classes.
- Priority+ pattern (Brad Frost).
- Baymard and NN/g on infinite scroll vs load more vs pagination, with item counts.
- Card sorting and tree testing as the method for labels and grouping.
- Search as navigation (hand-off to design-search for SEO side).

## Test briefs it should pass
- "Navigation for a B2B SaaS app with 9 sections, web and mobile."
- "Product listing for a 2,000 item catalog: infinite scroll or pagination?"
