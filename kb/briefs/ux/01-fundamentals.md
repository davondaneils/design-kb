# Brief: UX fundamentals (the gate)

Domain: UX and interaction design. Skill: design-ux. Owner hat: UX specialist.

## Question it answers
What must be true of every interactive screen before any craft, polish or novelty earns credit?

## After reading, a designer can decide
- Whether a screen passes the fundamentals gate, using a checklist that can be run in 5 minutes.
- How fast feedback must be for each action, and what kind of feedback to show.
- Whether an action needs a confirmation, an undo, or neither.
- Minimum target size, focus behavior and keyboard support for any control.

## Must cover
- Nielsen's 10 heuristics turned into checks, not a list to recite.
- Response time limits (0.1 s, 1 s, 10 s) and the 400 ms Doherty target.
- WCAG 2.2 AA interaction criteria: target size 2.5.8, focus not obscured 2.4.11, dragging 2.5.7, redundant entry 3.3.7, accessible authentication 3.3.8, consistent help 3.2.6.
- Undo over warnings (Raskin), confirmation dialog rules (NN/g).
- Real links vs buttons, URL as state, deep links, Back button behavior.
- Consistency with platform conventions (Jakob's law).

## Test briefs it should pass
- "Review this settings screen before we ship." The answer must find fundamentals misses first, in order of severity.
- "Should deleting a project ask 'Are you sure?'" The answer must reason about frequency, reversibility and stakes.
