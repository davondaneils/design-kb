# Brief: Onboarding and first run

## Question it answers
How does a new user reach first value fast, without a tour they will skip?

## After reading, a designer can decide
- Whether onboarding is needed at all, and what form it takes (none, contextual tips, interactive first task, setup checklist, tutorial).
- What to defer (account creation, settings, permissions, ratings).
- How and when to ask for permissions.
- How to measure it (time to value, activation event).

## Must cover
- NN/g study on deck-of-cards tutorials (70 users).
- Apple HIG onboarding and privacy permission guidance.
- Empty states as onboarding (NN/g).
- Baymard on deferring account creation.
- Practitioner sources on activation (labelled as opinion).

## Test briefs it should pass
- "Onboarding for a habit-tracking mobile app."
- "First-run for a team analytics SaaS that needs a data connection before it shows anything."
