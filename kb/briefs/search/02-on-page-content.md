# Brief 02: On-page and content structure

Owner hat: domain-specialist (search). Status: drafting. Brief date: 2026-10-09.

## Question it answers
What does a page need in its title, headings, copy and media so search engines and answer engines understand it, rank it and quote it accurately?

## After reading, a designer must be able to decide
- The title element and H1 for any page type, and when they should differ.
- Whether to write a meta description and what goes in it.
- Heading outline and where the direct answer sits.
- How to show first-hand experience and authorship (E-E-A-T is not a ranking factor, trust is the point).
- What makes content "non-commodity" in Google's 2026 terms.

## Must cover
- Google title link sources and the common rewrite triggers.
- Snippet behavior: Google mostly writes snippets from page text.
- Helpful content self-assessment: Who, How, Why. No preferred word count. Fake freshness is a warning sign.
- Answer-first structure (opinion with partial evidence), image alt text, video.
- Spam lines: scaled content abuse, keyword stuffing, site reputation policy.

## Test briefs
- "Write the title, meta description and outline for a pricing page for a B2B invoicing SaaS."
- "Our blog gets impressions but no clicks, help."
