# Brief 03: Structured data (schema.org)

Owner hat: domain-specialist (search). Status: drafting. Brief date: 2026-10-09.

## Question it answers
Which schema.org markup earns something real today (a rich result, entity clarity, merchant eligibility), which is dead weight, and how is it implemented without risk?

## After reading, a designer must be able to decide
- Which types to add for a given page type, from Google's current search gallery (25 features as of 2026-06-15).
- Which types no longer produce rich results (HowTo 2023, FAQ May 2026, the June and November 2025 cuts).
- Whether schema helps AI answers (2026 evidence: no measurable citation lift).
- JSON-LD placement, @id graph, matching visible content.

## Must cover
- Current gallery list and deprecation timeline with dates.
- Organization, WebSite (site name), BreadcrumbList, Article, Product (merchant listings), LocalBusiness, Review snippet rules (no self-serving reviews on LocalBusiness/Organization).
- Validation workflow: Rich Results Test, Schema Markup Validator, Search Console enhancement reports.
- Ahrefs 2026 difference-in-differences study on schema and AI citations.
